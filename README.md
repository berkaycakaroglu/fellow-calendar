# 📅 Fellow Calendar

[TR] **Fellow Calendar**, kullanıcıların kendi kişisel etkinliklerini planlayabildiği ve arkadaş grupları oluşturarak ortak takvimler üzerinden etkinliklerini senkronize edebildiği web tabanlı bir takvim uygulamasıdır.

[EN] **Fellow Calendar** is a web-based calendar application that enables users to manage their personal schedules and form friend groups to synchronize events on shared calendars.

---

## 🇹🇷 Türkçe

### 🚀 Özellikler
* **Kullanıcı Yönetimi:** Güvenli kayıt ve giriş sistemi.
* **Kişisel Takvim:** Günlük, haftalık ve aylık etkinlik planlama.
* **Arkadaş Grupları:** Grup oluşturma ve ortak takvim üzerinde etkinlik paylaşımı.
* **Duyarlı (Responsive) Arayüz:** Tüm cihazlarla uyumlu modern kullanıcı deneyimi.

### 🛠️ Teknolojiler
* **Backend:** Python / FastAPI (veya Flask)
* **Frontend:** HTML5, CSS3, JavaScript
* **Veritabanı:** SQLite / PostgreSQL
* **Versiyon Kontrol:** Git & GitHub
